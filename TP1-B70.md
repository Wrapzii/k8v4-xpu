# TP1 / single Arc Pro B70

Runs the K8/V4 int8-K / int4-V KV cache on ONE GPU (4 KV / 24 Q heads) and lets a
DFlash2 drafter share it. One library and one package serve the TP2 layout too —
nothing here is selected by an environment variable.

- `k8v4_v030/native/xe2_kv_ops.cpp` instantiates the kernels for both 2 and 4 local
  KV heads and dispatches at runtime from the head count the op tensors carry
  (cache shape `[blocks,64,HKV,256]`, query `[T,HQ,D]`). Any other count raises.
- `k8v4_v030/layout.py` replaces the module-level `HKV`/`HQ` constants with a frozen
  `PageLayout` built from the layer spec (`num_heads`/`num_kv_heads`); the backend,
  scratch, cache views, and prefill paths carry it, and unsupported counts raise.
- `k8v4_v030/compile_decode.sh` builds the one `build/libxe2_kv.so`
  (`--memory=1200m --memory-swap=4g`; the two-instantiation compile measured
  ~610 MiB peak container memory).
- `k8v4_v030/compile_sdpa.sh` builds `build/libk8v4_sdpa.so` and copies
  `libdnnl.so.3` out of the compile image's bundled oneDNN (`$TORCH/lib` in
  `k8v4-compile-2026`); the serving image ships that copy beside the sdpa
  library. `k8v4_v030/compile_image.sh` builds the compile image itself.
- `Dockerfile.tp1` (repo root) -> `vllm-openai-xpu:v0.30.0-k8v4-tp1`: MLP W4A8
  prefill, INT8 embedding, and the K8/V4 backend on the 4-head layout. The
  image build only greps the library for the s1-paged kernel symbols
  (`Xe2KvTorchAbiS1PagedKernel<2>/<4>`); the other ops are exercised by the
  test suite, not by the build check.
- `k8v4_v030/Dockerfile.tp1-skip` + `tools/patch_vllm_skip_fp8.py` (optional) ->
  `...-tp1-skip`: vLLM patches so `--kv-cache-dtype-skip-layers` layers (the
  drafter, 64-68) run the stock XPU flash backend on fp8 next to the K8/V4 target.
  The XPU flash kernel ignores the block stride, so padded pages are spread over
  the tokens and the drafter block is a 64-multiple dividing the page.
- Build: `bash k8v4_v030/compile_decode.sh && bash k8v4_v030/compile_sdpa.sh`,
  then from the repo root `docker build -f Dockerfile.tp1 -t vllm-openai-xpu:v0.30.0-k8v4-tp1 .`,
  then `-f k8v4_v030/Dockerfile.tp1-skip` for the drafter image; pass
  `--build-arg BASE=<base tag>` when the base carries a suffix (e.g. `...-pr`).
- `bench/graph_sweep.py` always emits the library sha256 but pins nothing by
  default; pass `--expected-sha` to compare a run against a known digest.
- Serve flags and measurements: https://huggingface.co/davetha/Huihui-Qwen3.8-27B-abliterated-AutoRound-Int4-baked-embed-int8
